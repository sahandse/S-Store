# فروشگاه افزونه اس — S Store

S Store مرکز نصب، مدیریت و بروزرسانی افزونه‌های اختصاصی Sahand Rezvan برای وردپرس است.

## نسخه 1.5.0

نسخه 1.5.0 رابط مدیریتی S Store را از نو طراحی می‌کند:

- داشبورد گرافیکی و مینیمال جدید
- کارت‌های آماری برای کل افزونه‌ها، نصب‌شده‌ها، بروزرسانی‌ها و افزونه‌های فعال
- جستجوی زنده و فیلتر دسته‌بندی افزونه‌ها
- کارت‌های جدید نصب / فعال‌سازی / بروزرسانی
- صفحه جزئیات مستقل برای هر افزونه
- نمایش ویژگی‌ها، سازگاری، تغییرات نسخه و وضعیت نصب
- صفحه بروزرسانی جدید با بروزرسانی مستقیم
- گزینه بروزرسانی خودکار افزونه‌های S Store
- هماهنگی ظاهری بیشتر با پنل مدیریت وردپرس
- سیستم Update بر اساس Manifest مرکزی و slug ثابت
- پشتیبانی از ثبت Native تنظیمات افزونه‌ها زیر منوی S Store

## ساختار

- `plugins/<slug>/` سورس مستقل هر افزونه
- `shared/design-system.css` دیزاین سیستم مشترک
- `manifest/plugins.json` نسخه‌ها و لینک ZIP افزونه‌ها
- `.github/workflows/release-plugin.yml` ساخت ZIP و Release افزونه‌ها

## انتشار نسخه جدید افزونه‌ها

1. سورس افزونه را در Repo خودش تغییر دهید.
2. Version هدر افزونه را افزایش دهید.
3. ZIP باید در ریشه فقط فولدر همان slug را داشته باشد.
4. Manifest مرکزی S Store نسخه و لینک دانلود را دریافت می‌کند.
5. سایت‌های دارای S Store نسخه جدید را به‌صورت Update همان افزونه می‌بینند.
