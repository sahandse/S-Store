# S Store — فروشگاه افزونه اس

**Version: 1.5.0**

مرکز نصب، مدیریت و بروزرسانی افزونه‌های اختصاصی WordPress.

## امکانات نسخه 1.5.0

- داشبورد کاملاً بازطراحی‌شده و مینیمال
- آمار کل افزونه‌ها، نصب‌شده‌ها، فعال‌ها و بروزرسانی‌ها
- جستجوی زنده افزونه‌ها
- فیلتر دسته‌بندی
- کارت‌های گرافیکی جدید
- صفحه جزئیات مستقل برای هر افزونه
- نمایش وضعیت نصب، نسخه و سازگاری
- بروزرسانی مستقیم افزونه از S Store
- گزینه بروزرسانی خودکار افزونه‌های S Store
- صفحه جدید بروزرسانی‌ها
- ظاهر یکپارچه‌تر با wp-admin
- پشتیبانی از منوی Native افزونه‌ها زیر S Store
