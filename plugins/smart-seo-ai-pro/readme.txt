== Description ==

Smart SEO AI Suite Pro is a complete, production-ready WordPress plugin that unifies search engine optimization, generative AI copywriting, WooCommerce audit, malware/code security scanning, speed profiling, and automated issue resolution with instant rollback capabilities.

### Key Features:
* **SEO Engine**: Real-time content analysis, title length, meta description, H1-H3 hierarchy, keyword density, internal/external link auditor, and image ALT validator with 0-100 score.
* **AI Engine**: Connects with Google Gemini, OpenAI (GPT-4o), and Anthropic Claude for generating click-magnet SEO titles, descriptions, keyword suggestions, outlines, and WooCommerce product descriptions.
* **WooCommerce Optimizer**: Complete store scanner analyzing product titles, short descriptions, galleries, prices, SKUs, and injecting structured Product JSON-LD Schema.
* **Security Engine**: Deep scan for suspicious PHP functions (`eval`, `base64_decode`, `shell_exec`, `gzinflate`, `passthru`), SSL checker, WP_DEBUG exposure guard, and admin username safety.
* **Performance Engine**: Monitors peak RAM usage, PHP version compatibility, database revisions, expired transients, and heavy images.
* **AutoFix Engine with Rollback**: Fixes missing Alt tags and meta descriptions automatically with pre-change backup and one-click rollback.
* **Interactive Dashboard & Reports**: Modern visual dashboard, history log, CSV exports, and printable PDF reports.

== Installation ==

1. Upload `smart-seo-ai-suite-pro-final.zip` via **Plugins > Add New > Upload Plugin** in your WordPress Admin.
2. Activate the plugin through the **Plugins** menu.
3. Access **Smart SEO AI** from your WordPress admin sidebar.
