A bilingual support and live-chat button for WordPress with FAQ, social links, operators, themes, working hours and optional Bale integration.

== Description ==

Support Button is a flexible customer-support plugin for WordPress. It adds a customizable floating support button and a modern support panel to your website, while giving administrators a central inbox for visitor conversations.

The plugin is designed for public WordPress websites that need a lightweight support experience without forcing visitors to leave the site. Site owners can customize the launcher image, chat appearance, support content, FAQ items, social links, support operators and working hours from the WordPress admin panel.

= Main features =

* On-site visitor chat with a WordPress admin inbox
* Persian and English interface content
* RTL and LTR support
* Custom launcher image, text, size, position and animation
* Multiple support-panel layouts and visual themes
* FAQ management in Persian and English
* Custom social network links with custom images/icons
* Support operator profiles and offline contact links
* Manual or scheduled online/offline status
* Configurable working hours for each day of the week
* Optional Bale Bot notifications and webhook replies
* Automatic cleanup of old conversations based on retention settings
* Privacy-oriented settings for stored conversations

= Who is it for? =

Support Button is useful for stores, company websites, service websites, blogs and other WordPress sites that want to provide a simple support channel directly on their website.

= External service: Bale =

The Bale integration is optional and disabled by default. When enabled, the plugin may send support message text and conversation identifiers to Bale through the Bale Bot API endpoint configured by the site administrator. A Bale bot token and destination chat ID are required.

Site administrators are responsible for reviewing Bale's terms of service and privacy practices before enabling this integration. No Bale data is sent when the integration is disabled.

== Installation ==

1. Upload the plugin ZIP in Plugins > Add New > Upload Plugin, or install it from the WordPress plugin directory when available.
2. Activate Support Button.
3. Open Support > Settings.
4. Configure the button appearance, support panel, FAQ, social links, operators and working hours.
5. Optionally configure Bale Bot integration.

== Frequently Asked Questions ==

= Does the plugin require Bale? =

No. The on-site support button, FAQ, social links and chat can be used without Bale. Bale integration is optional.

= Can I use my own support button image? =

Yes. You can select an image from the WordPress Media Library and customize button size, position, colors and animation.

= Does it support Persian and English? =

Yes. The plugin includes Persian/RTL and English/LTR support, and provides separate fields for key visitor-facing content.

= Can I add custom social networks? =

Yes. You can add custom names, URLs and images/icons for your social or messaging links.
